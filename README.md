# SMART-X Twin Framework

A modular, AI-driven digital twin framework for real-time urban traffic control and analysis, integrating:
- Edge computing (Raspberry Pi)
- Multi-agent reinforcement learning (MARL)
- GAN-based synthetic data generation
- Explainable AI (XAI)
- Interactive 3D visualization (Three.js, SUMO)

## Features
- Real-time vehicle-to-digital twin (V2DT) synchronization
- Edge AI for low-latency inference
- Interactive visual insights via XAI
- LLM-based natural language querying (LLaMA)
